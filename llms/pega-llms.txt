# Pega (Pegasystems)

> Pega is an enterprise low-code platform for AI-powered decisioning and workflow automation, spanning business process management (BPM), CRM, and customer engagement. External systems integrate through the Constellation Digital Experience (DX) API — a REST + OAuth 2.0 surface for creating and driving cases and data objects — and through first-party SDKs that render Constellation DX Components.

## APIs
- Pega DX API overview: https://docs.pega.com/bundle/platform/page/platform/dx-api/dx-api-overview.html
- DX API base path (per-tenant): https://<appURL>/dx/api/application/v2
